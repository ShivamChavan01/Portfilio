# PATTERN SYNTHESIS — What ~50 real portfolios agree on

Sources: `minimalists.md` (12 legendary minimalist dev portfolios) · `ai-engineers.md` (15 prominent AI/ML engineers) · `trending-2026.md` (15-27 current-gen sites) · `hiring-signals.md` (HN threads + hiring-manager survey).

## The consensus

1. **Hero = name + one-line role + one terse positioning sentence.** 12/12 minimalists, 13/15 AI engineers. **No CTA buttons, no photo, no chips in the hero.** Socials = plain text links (9-10/12).
2. **Projects = flat editorial rows, NOT card grids** — 9/12 minimalists; trending-2026 confirms ("bento grids are template-hype, 1/15 ship one"). Row anatomy: linked title + year + ≤20-word one-liner + tech chips + ONE hard metric.
3. **"Currently building X" / now-element near the top** — 8/15 AI engineers, 9/15 trending.
4. **Near-monochrome + exactly ONE accent** — 9/12 minimalists; rainbow/gradients read dated. Light theme default (10/12), dark optional.
5. **Sans (Inter/system) + mono pairing** — 10/12 minimalists, 18/18 trending run Inter/Geist. Serif display is a legitimate differentiator (one signature idea per site).
6. **Writing/decision-process as the credibility engine** — 11/15 AI engineers run a dated writing list; hiring research: posts exposing decisions now weigh MORE (AI slop erased proof of authorship). Case studies = the equivalent.
7. **OSS linked from the homepage** — 12/15 AI engineers (repo links, not PR links).
8. **Single narrow column, ≤7 nav items, generous whitespace** — 8/12 minimalists.
9. **Motion = utility only** (theme swap, copy email). One signature interaction max. "Interactivity scales inversely with seniority — seniors ship pure text + numbers" (trending).
10. **Hiring signals**: deployed software with real users, OSS with visible review history, decision-process writing, evals/ground-truth for AI claims. Killers: template look, walls of text, buzzwords, broken links, skill bars (0/15 prominent engineers have them).

## Verdict on our current build

| Keep (already consensus) | Fix (violates consensus) |
|---|---|
| Positioning-sentence hero, "currently building" line | ❌ CTA buttons + pill socials in hero → text links |
| One accent (terracotta) on warm cream, serif signature | ❌ 2-col project CARD grid → flat editorial rows |
| Mono metadata layer, ≤7 nav items, colophon, no fake metrics | ❌ Experience/Open-source cards → hanging-date rows |
| Case studies as expandable depth (decision-process writing) | ❌ Case-study cards → flat expandable rows |
| Theme toggle (the one signature interaction) | ❌ Soften any leftover "startup-pill" chrome |

## Target form

Editorial text-first page on warm cream: name/role hero → positioning sentence → social text links → numbered sections (Selected work / Case studies / Experience / Open source / Contact) as hairline rows with mono metadata and one hard metric each → contact with serif close. Serif + terracotta mark = the one signature. Everything else stays quiet.
